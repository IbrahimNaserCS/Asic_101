RTL: A way to model digital circuits, uses something like Verilog. 
Netlist: A list of electronic components and the nodes they are connected to. 
SDC: A file format describing timing intent.
Liberty: Describes relationships between cells.
LEF: Describes the physical properties of cells.
DEF: Describes the placement or routing level.
ODB: A database representation for OpenROAD.
SPEF: Information about parasitic resistance. 
SDF: Represents timing delays.
SPICE: Transistor level netlist representation.
GDSII: A geometric representation.
